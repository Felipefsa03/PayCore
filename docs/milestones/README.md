# Documentação por milestone

Cada milestone entrega um pacote navegável com escopo, decisões, demonstração, checklist e
retrospectiva. O objetivo é que qualquer pessoa consiga reconstruir **o que foi prometido,
o que foi provado e o que ficou pendente** sem depender de conversas ou histórico de chat.

## Pacote mínimo por milestone

| Documento | Pergunta que responde | Obrigatório a partir de |
| --------- | --------------------- | ----------------------- |
| Escopo e dependências | O que entra, o que fica fora e do que depende? | M1 |
| Demonstração | Como provar o resultado em um clone limpo? | M1 |
| Checklist de entrega | Todos os critérios foram cumpridos e onde está a evidência? | M1 |
| Retrospectiva | O que funcionou, o que atrapalhou e quais ações ficaram? | M1 |
| ADRs e modelo de ameaças | Quais decisões estruturais foram tomadas e quais riscos restam? | M1 |

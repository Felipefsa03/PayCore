## 7. Reprodução

```sh
export PAYCORE_IT_JDBC_URL='jdbc:postgresql://<host>:<porta>/paycore_it'
export PAYCORE_IT_DB_USER='<usuario>'
export PAYCORE_IT_DB_PASSWORD='<senha>'
make test
make coverage-summary
make docs-check
make security-check
```

Sem Docker, omita Testcontainers e use o modo externo acima. Sem Node, o lint do contrato
não é reexecutado, mas a evidência anterior permanece válida.

## 8. Limitações desta execução

1. **Sem Docker:** `make up/down/logs/reset` não foram executados; `make test` usou um
   PostgreSQL externo. A falha de `make up` é explícita e documentada.
2. **Sem Node:** o lint do contrato não foi reexecutado nesta execução; a evidência do
   card anterior permanece.
3. **Sem CI disparado:** `gh` e token de GitHub estão indisponíveis; o artefato
   `financial-core-reports` será publicado quando o PR for aberto/mergeado. A matriz mínima
   foi executada localmente com o mesmo comando do CI (`./mvnw -B verify`).
4. **Cobertura de branches abaixo da meta** (61,8% vs. 70%): lacuna registrada com dono e
   prazo em `estrategia-de-testes.md` §7.
5. **Sem teste de concorrência, idempotência ou ledger balanceado:** requisitos P0 de
   transferência ainda não implementados (M2).
